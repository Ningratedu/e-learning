Format Upload Soal via Excel

File Excel (.xlsx) harus memiliki 1 baris header lalu 1 baris untuk setiap soal, dengan urutan kolom berikut:

PertanyaanOpsi AOpsi BOpsi COpsi DJawaban Benar
Apa kepanjangan TNA?Training Need AnalysisTotal Nilai AkhirTim Nilai AbsensiTarget Nilai AnggaranA
  • Kolom Jawaban Benar diisi salah satu huruf: A, B, C, atau D (sesuai opsi yang benar).
  • Soal hasil import akan ditambahkan ke daftar soal yang sudah ada, tidak menimpa soal lama.
  • Boleh diisi lebih dari 4 opsi jawaban? Tidak — sistem hanya membaca kolom Opsi A–D.
  • Simpan file dalam format .xlsx sebelum diupload.
